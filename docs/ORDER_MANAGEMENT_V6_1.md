# V6.1 Order Management

## Admin
- Order list with customer, total, item count, date, status.
- Inline status dropdown.
- Order detail modal.
- Customer/contact/shipping/payment details.
- Order items with product thumbnails.
- Status timeline.
- Admin can update the order status.

## Customer
`/account.html` now shows:
- order history
- current status
- visual progress timeline
- cancellation notice

## Statuses
`pending` -> `paid` -> `processing` -> `shipped` -> `completed`

Alternative terminal status:
`cancelled`

## Important
Payment is still mock/demo. No real transaction or automatic payment confirmation exists yet.
